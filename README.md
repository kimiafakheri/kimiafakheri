# 🔬 Selected Projects:

- **Privacy-Preserving Machine Learning & Unlearning**  
  Implemented and evaluated the SISA framework for machine unlearning, studying trade-offs between privacy preservation, computational efficiency, and model utility.

- **Reinforcement Learning for Robotic Control**  
  Developed a 2-DOF robotic reaching environment and evaluated classical and deep reinforcement learning approaches, including SARSA and DDPG.

- **Computational Models of Visual Attention**  
  Studied human visual attention by combining eye-tracking analysis with computational saliency models to compare predicted and observed gaze behavior.

- **Feature Optimization for Visual Recognition**  
  Applied genetic algorithms for feature selection and optimization in the HMAX visual recognition framework.
